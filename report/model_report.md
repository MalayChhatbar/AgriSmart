# AgriSmart AI — Model Report (Section 7.3)

| Field | Detail |
|---|---|
| **Task** | Crop-disease image classification, **38 PlantVillage classes (28 shared with PlantDoc)** including 14 crops (Apple, Blueberry, Cherry, Corn, Grape, Orange, Peach, Pepper, Potato, Raspberry, Soybean, Squash, Strawberry, Tomato) + healthy. Predicts exact label string (e.g., `Tomato___Early_blight`). |
| **Dataset & Split** | PlantVillage ~54k lab images (uniform background) + PlantDoc TRAIN field split (real phone photos, clutter/occlusion). **PlantDoc TEST 236 images, 27 classes** is strictly held-out — never trained on, never used for checkpoint selection. Val = 10% PlantVillage + 20% PlantDoc TRAIN (`field-val` for selection). Extra public data (Plant Pathology 2021 apple) optional best-effort; core still evaluated on provided field set. |
| **Model / Approach** | `timm` `convnext_small.fb_in22k_ft_in1k` (pretrained IN22k→IN1k), 2-phase: Phase1 PV-only 6 epochs → Phase2 PV+PlantDoc field (field oversample ×3, PV subset 12k) 10 epochs. AdamW + OneCycle (head 8e-4, backbone 8e-5), MixUp/CutMix + EMA (0.999), LabelSmooth 0.1. Aug: synthetic+real background replace p=0.9, field-photo sim (shadow/blur/noise/JPEG/low-res/white-balance) p=0.75. 4-view TTA (1.0 + flip, 1.33 + flip), temp scaling (T=1.0, Cell2 calibrated), restricted to 28 shared classes, CLIP branch (ViT-B-32, α=0.75) disabled this export. |
| **Metric & Result** | **Primary Macro-F1 on held-out PlantDoc TEST (field): 0.7412** / Accuracy 0.7500 / Top-3 0.9661 / ECE 0.0500 (CNN restricted+TTA, CLIP ensemble same this run). Plain (no TTA/restriction): 0.7231. Lab val macro-F1 0.9978 (optimistic, domain gap). Confusion matrix `report/confusion_matrix.png` and `per_class_report.txt` below; weakest: `Corn Cercospora 0.167 (n=4)`, `Tomato Bacterial Spot 0.308`, strongest `Squash Powdery Mildew 1.0`, `Strawberry healthy 1.0`. See `model/meta.json` metrics. |
| **Baseline** | Lab-only ResNet-50 baseline ~0.89 F1 on PlantVillage, but **field F1 ~0.62** when trained PV-only without field robustness (reported in Cell1 ablations). Ours **+0.12 field F1** via 2-phase + field aug + background replace. |
| **Limitations** | Lab→field drop remains (0.997→0.741) — real-field lighting/occlusion not fully solved. Rare PlantDoc classes (n≤4) fragile. Leaf-fraction gate (0.04) and low-conf threshold (0.55) are heuristics, not guarantees against OOD (wall, whole plant, non-crop). ONNX export in repo is stale (previous training) — will be replaced; heuristic fallback ensures reproducibility now. See Cell2 for calibration/self-training/RL that further close gap. |

**Held-out field TEST (restricted+TTA, 236 images):** accuracy 0.75 / macro-F1 **0.7412** / weighted-F1 0.749 / ECE 0.05. Full per-class table in `per_class_report.txt`; matrices: `confusion_matrix.png` (restricted+TTA) and `confusion_matrix_plain.png`.
